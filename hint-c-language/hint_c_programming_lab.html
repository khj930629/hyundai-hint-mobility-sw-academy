웹 실습기 vs Visual Studio 실행 차이 안내

1. 소스 파일 확장자: main.c vs main.cpp (교재 p.35~36, p.44)

Visual Studio에서 새 항목을 추가할 때 기본 파일명이 main.cpp로 생성됩니다. C언어 표준 문법으로 컴파일하려면 파일 이름을 main.c로 변경해야 합니다.

2. 문자 인코딩: CP949 vs UTF-8 (교재 p.38, p.45)

Windows Visual Studio 콘솔은 기본적으로 한글 인코딩(CP949)을 사용하며, 이 웹 플랫폼은 UTF-8을 기본으로 지원합니다.

3. scanf() 보안 경고 (교재 p.83)

Visual Studio에서는 scanf() 사용 시 보안 경고가 발생할 수 있어 코드 최상단에 #define _CRT_SECURE_NO_WARNINGS를 추가합니다. 본 웹 실습기는 두 방식 모두 그대로 실행됩니다.

4. Windows 전용 헤더 <Windows.h> / Sleep() (교재 p.42, p.44)

Sleep(1000)은 밀리초(ms) 단위로 대기하는 Windows 전용 함수입니다. 웹 실습기에서는 안전한 범위(최대 2초)로 시뮬레이션됩니다.
